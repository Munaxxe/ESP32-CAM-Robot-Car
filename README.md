## ABOUT THE PROJECT

The **ESP32-CAM Robot Car** is a wireless robotic vehicle designed to demonstrate remote-controlled mobility and real-time visual monitoring using the ESP32-CAM microcontroller.

The system integrates wireless communication, motor control, and camera streaming to allow a user to remotely operate the robot while viewing its surroundings.

Through a Wi-Fi connection, the robot can receive movement commands and transmit live visual feedback, providing a practical exploration of embedded systems, robotics, and Internet of Things (IoT) technology.
